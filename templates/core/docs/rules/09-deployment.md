# 09 部署规范

编排工具（Compose、K8s、平台 Publish）由项目 overlay 写清。本文是通用底线。

## 配置

- 仓库提供配置样例（如 `.env.example`），标注含义、默认、是否必填。
- 真实密钥、生产口令不进 git、不进镜像层。
- 可变项（URL、超时、开关）从环境或配置中心读，启动时校验占位符未替换则失败。

## 发布

- 构建产物与 git 修订可追溯。
- 健康检查失败不要接流量。
- 回滚：换回上一份可运行产物；结构变更的回滚以该迭代 `plan.md` 为准。

## 运行

- 日志走规范文件描述的级别与脱敏，不在容器参数里打印密钥。
- 对象存储或文件桶的权限按 overlay：默认私有，下载用短时凭证，不持久化签名 URL。

## 禁止

- 用开发调试账号当生产凭据。
- 无文档的「手工改线上库」。
- 把本机覆盖文件（`docker-compose.override`、`.env`）提交进库。
