# 07 数据库设计规范

物理表名、前缀、具体引擎写在 overlay `architecture.md`。本文与引擎无关。

## 事务

- 事务只包本地数据读写。禁止在事务中调用网络、对象存储、模型推理或发送邮件。
- 需要外部结果时：短事务写出意图或读快照 → 调外部 → 另一短事务写结果。
- 提交成功前不要对用户宣称已成功。

## 完整性

- 用约束表达不能坏的规则（非空、检查、外键、唯一），不要只靠应用层碰运气。
- 按查询路径建索引；归属隔离字段应出现在常用索引前缀。
- 删除父实体时写明子实体策略（级联或限制），禁止静默孤儿行。

## 注释与目录

- 表与字段必须有**用途**注释（模型层与库内 DDL 一致，若项目用 ORM）。
- 若项目有表结构目录，任何 FEAT/BUG 改表必须同步该文件。禁止只改模型。

## 迁移

- 破坏性变更（删列、改名、无默认 NOT NULL）先问再做，并在 plan 写回滚。
- 禁止用「删库重建」当生产迁移。存量类型变更必须有失败策略，禁止静默丢掉无法转换的值。

## 隔离

查询与写入按登录身份过滤，禁止信任请求体里的身份字段。
