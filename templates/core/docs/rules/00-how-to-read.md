# 00 如何读细则

- **执行**：AI 编码工具与门禁只认 `.agent/`。冲突以 `.agent/` 为准。
- **展开**：本目录 `01`–`10` 给人与模型按需阅读，解释场景与检查清单。
- **分层**：`01`–`10` 与业务无关，换项目仍成立。产品红线、模块地图、技术栈命令只写在 `.agent/constraints.md`、`architecture.md`、`design.md` 与 `verification.md` §1.1。
- **Tokens**：不要把本目录全文塞进指针文件（`AGENTS.md` 等）。需要某条时打开对应编号文件。
