## 2. 认证、存储与对外边界

由项目填写真实边界。至少写清：

- 认证唯一实现与身份隔离字段（禁止信任请求体里的身份字段）。
- 对象存储或文件落点（禁止把签名 URL 当持久数据）。
- 前端访问后端的唯一出口（禁止页面内散落裸 HTTP 客户端，除非本项目明确允许）。

## 3. 配置

- 禁止把可变参数（URL、超时、模型名、限额、路径）硬编码进业务代码。
- 新增或变更配置项必须同步写入项目的配置样例文件，标注含义、默认值、是否必填。

## 4. 日志与脱敏

日志**禁止**记录：密钥、完整个人身份信息、签名 URL、业务正文全量、prompt 全文。需要观测长文本时只记录长度与摘要特征。

## 5. 先问再做

- 引入新依赖、新第三方服务或新密钥。
- 破坏性 DDL（删列、改名、无默认值的 NOT NULL）。
- 变更既有 API 契约或技术选型。
- 需求存在两种以上合理解释时。
